# Protocole de développement AXIOM

Ce dépôt suit `~/DEV-PROTOCOL.md` et les règles locales de `.devin/provider-rules.md`.

- **Orchestration** : l'agent chargé du chantier planifie et arbitre avec un modèle disponible ; aucun visa Fable n'est requis.
- **Implémentation** : lots avec fichiers attribués ; travaux indépendants en parallèle lorsque cela aide.
- **Revue** : agent indépendant pour les changements, particulièrement la sécurité et les calculs financiers.
- **Règles** : français, simplicité, architecture décrite dans `BUILD-CONTRACT.md`, tests adaptés et preuves réelles.
- Les demandes et autorisations du propriétaire priment ; ne pas bloquer le chantier sur l'indisponibilité d'un modèle.
