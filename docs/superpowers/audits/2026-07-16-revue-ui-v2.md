# AXIOM Terminal — Revue UI v2 : uniformité, lisibilité, ergonomie + features

**Date :** 2026-07-16 · **Méthode :** audit multi-agents (8 lentilles code + 3 éclaireurs features + contre-expertise adversariale des findings haute sévérité) complété d'un passage visuel sur l'app live (thème Bloomberg, captures).
**Périmètre :** tout ce qui a divergé depuis le lot d'uniformisation du 2026-07-09 (commit `3ce9b83`, ~184 fichiers modifiés depuis, +25 k lignes).
**Bilan brut :** 125 findings — 20 haute (17 CONFIRMÉ, 2 PLAUSIBLE, 1 RÉFUTÉ), 63 moyenne, 42 basse — et 22 candidats features fondés sur les données déjà branchées.

---

## 1. Verdict global

Le standard du 9 juillet (spec §2 + fondations `lib/format` / `ui.tsx` / `canvasTokens` / `--serie-1…6`) **tient bien sur le périmètre qu'il a migré** — mais **tout ce qui a été construit après re-diverge**, exactement comme la première fois : les lots liquidations/globe/stablecoins/taskbar ont réintroduit hex en dur, formatters locaux, boutons ad hoc et conventions d'en-tête divergentes. Le standard est un instantané, pas un garde-fou : **rien ne l'applique aux nouveaux fichiers** (aucun lint/test ne bloque un hex de série dans `chart/`, une duplication de `fmtFunding`, un `bg-surface` actif).

Trois problèmes dominent tout le reste :

1. **[Systémique — CONFIRMÉ] Les modificateurs d'opacité Tailwind sur les tokens sont des no-op.** `tailwind.config.js` déclare les couleurs en chaînes `var(--…)` sans `<alpha-value>` : **toutes** les classes `bg-accent/15`, `border-down/40`, `bg-surface/80`… (15+ fichiers, y compris `ErreurBloc` et `BadgeFiabilite` du module standard) ne génèrent **aucune règle CSS**. Conséquences vécues à l'écran : la ligne sélectionnée au clavier dans la palette ⌘K est invisible (navigation ↑/↓ à l'aveugle), le SymbolBanner superposé au chart est transparent, l'ErreurBloc « consacré » n'a jamais eu sa bordure rouge. Le standard §2 consacre même `border-down/40` — la spec elle-même prescrit une classe qui ne fait rien.
2. **[Systémique — CONFIRMÉ] Le chart a entièrement échappé aux tokens.** Les ~98 indicateurs du catalogue sont enregistrés sans `styles` (palette klinecharts par défaut, identique sur les 5 thèmes) ; toutes les couleurs de série ajoutées depuis le lot (derivatives, macro, revenue, ecoMarkers, compare, navigation) sont des hex figés ; `canvasTokens` n'est consommé dans `chart/` que par `tradeMarkers.ts`, et le lecteur de tokens est re-dupliqué localement dans 6 fichiers. Sur Bloomberg, les niveaux de liquidation ESTIMÉS (orange figé) sont indiscernables de la heatmap réelle (rampe ambre) — le garde-fou visuel promis est faux sur ce thème.
3. **[Lisibilité — CONFIRMÉ de visu] Des nombres bruts illisibles à l'écran.** Le pane macro affiche « Cap crypto: 2,293,577,001,928.3072 » et un axe Y « 20,000,000,000,000.0000 » ; le pane OI a le même défaut (pas de `precision`/`shouldFormatBigNumber`, corrigé pour le seul `revenue.ts`) ; le CVD s'affiche à 4 décimales. Côté fenêtres : funding en 3 implémentations divergentes, fraîcheur en 4 variantes, DVOL en 2 conventions.

Et un constat vécu pendant le passage visuel : **taper `DERIV` + ⏎ dans la palette a changé la paire globale vers DERIVUSDT** (un vrai token) au lieu d'ouvrir la fenêtre Dérivés — silencieusement, sans confirmation ni undo. Toutes les fenêtres se sont mises à afficher $0.00 et « — » sans explication. L'ambiguïté symbole/commande de la palette est un piège réel.

Sur le volet **synthèse** (ta demande « moins de chiffres bruts, plus de lecture ») : le terminal aligne des valeurs sans référentiel — un funding de +0.0100 % n'est ni « haut » ni « bas » à l'écran, MVRV-Z/SOPR/NUPL sont en 4 décimales sans zone, $8M/h de liquidations n'a pas de baseline, et le BRIEF (fenêtre de synthèse !) n'a pas de synthèse chapeau. Or **le daemon accumule maintenant l'historique** (liquidations 30 j, funding avec z-score `zScoreFunding` côté daemon, snapshots KV) : la contrainte qui avait fait écarter REGIME/ALRT v2 au lot précédent est levée.

## 3. Findings moyens — les motifs récurrents (63)

Détail complet en annexe ; les familles qui comptent :

- **« bg-surface actif sur fond bg-surface »** : l'état actif de bascules/filtres est invisible dans MacroRates, Onchain (ETF), News (#SYMBOLE) — le standard dit `bg-bg`.
- **Boutons/onglets recopiés à la main** au lieu des primitives : Taskbar (BTN_SECONDAIRE divergent), DomWindow (Onglets), Watchlist (menu ⚙ sans Échap/clavier), MarketMap (en-tête à la main), Portfolio (variantes ad hoc).
- **Couleurs sémantiques manquantes** : pas de token `--warn` (amber-500 en dur dans ≥5 fichiers), `accent-emerald-500` figé (MacroPanel), `bg-violet-500`/`text-sky-400` (Toolbar), cyan navigation, `#ec4899` gdelt dupliqué TickerBand/News.
- **Canvas** : `ctx.font = "10px var(--font-display)"` silencieusement ignoré (CourbeTaux) ; alpha hex concaténé à un token (`colDown + "33"`, Backtest) ; VPFR à opacité pleine qui masque les bougies ; footprint + heatmap liq sans garde d'empilement.
- **Ergonomie** : AZERTY — les raccourcis 1–9 ne marchent qu'avec Shift ; « 1m/1M » mnémoniques confondus ; ⌘K sur fenêtre minimisée la FERME au lieu de la restaurer ; taskbar sans wrap (déborde à ~8 fenêtres) ; tailles par défaut non plafonnées sur laptop ; O/L/R no-op silencieux ; aucun moyen de retrouver son plan de fenêtres après reload.
- **Sécurité de saisie** : suppression de position ouverte en 1 clic sans confirmation (Portfolio) vs double-clic armé (Alerts) ; formulaires qui avalent silencieusement les saisies invalides.
- **Hiérarchie** : VOL relègue ses 4 chiffres clés (RV30/DVOL/VRP/z-score) en 11px tronquable dans l'en-tête ; OI affiché 2× dans DERIV sans réconciliation ; depeg invisible depuis l'onglet par défaut de STBL ; écart CEX/DEX (« le signal » déclaré de FUNDX) en texte neutre sans seuil ; screener sans mise en évidence des extrêmes.

## 4. Features différenciantes — 22 candidats, sélection recommandée

Les 3 directions demandées (aide à la décision, orderflow avancé, confort opérateur), tous fondés sur des sources **déjà branchées** (fichiers vérifiés par les éclaireurs). Détail complet en annexe.

### Aide à la décision — la couche qui manque
| Nom | Effort | Pitch court |
|---|---|---|
| **XSTAT** | S | Percentile 30 j sur funding / ΔOI / $liq/min / DVOL — « funding BTC = p97/30 j » en Badge dans DERIV, LIQ, BRIEF. Le référentiel local SQLite rend chaque chiffre interprétable. |
| **BRIEF+** | S | 2-4 « points d'attention » déterministes en tête du BRIEF (« Funding p95 + ΔOI +6 % : positionnement long tendu »), règles pures testables, zéro LLM. |
| **REGIME** | M | Score composite risk-on/neutre/risk-off (funding, ΔOI, DVOL, F&G, dominance, flux stablecoins) affiché en permanence dans le chrome + détail par composant. |
| **PULSE** | M | HUD des anomalies du moment : bande priorisée des 3-5 choses anormales MAINTENANT (z-score funding, cascade en cours, divergence CVD active, depeg, source dégradée), clic = fenêtre concernée. |
| ALRT2 | M | Alertes composées ET (funding-extreme ET liq-cascade) évaluées onglet fermé par le daemon. |
| SQZ | S | Preset screener « anomalies » trié par score de squeeze (funding × ΔOI × retail vs top traders). |
| EVGARD | S | Garde d'événement : « CPI dans 42 min — 2 positions BTC ouvertes » + playbook FOMC en 1 clic. |

### Orderflow avancé
| Nom | Effort | Pitch court |
|---|---|---|
| **CVDX** | S | Croisements CVD spot/perp détectés + badge horodaté sur le pane (les séries rebasées existent déjà, il manque la détection). |
| **DELTAMAP** | S | Profil de delta par niveau de prix — seconde projection du buffer footprint déjà accumulé, révèle l'absorption. |
| ABSORB | M | Détection absorption/exhaustion sur cellules footprint, badges sur le chart. |
| CASCADE+ | M | Scoring des cascades (vitesse, accélération, mix venues) + rang percentile 30 j (« cascade top 5 % du mois »). |

| SWEEP | M | Big prints/sweeps corrélés au carnet local (quels murs ont été mangés). Contrainte : assouplir le budget 1-WS de DOM. |

### Confort opérateur
| Nom | Effort | Pitch court |
|---|---|---|

| **FOCUS** | S | Mode focus : tout minimiser sauf la fenêtre/groupe actif, toasts non critiques coupés, restauration exacte en sortie. |

**Sélection recommandée pour un premier lot features** (synergie maximale avec les findings lisibilité, coût S dominant) : **XSTAT + BRIEF+ + REGIME** (ils réparent H16-H19 en les dépassant), puis **CVDX + DELTAMAP** (orderflow, S), puis **JRNL-CHART + FOCUS + WS-KEYS** (confort, S). Les M/L restants sont documentés comme suites.

## 5. Plan de bataille proposé (3 lots)

1. **Lot A — Fondations durcies + conformité** (correctifs, pas de feature) : support alpha des tokens (`--*-rgb` + `<alpha-value>`) qui répare d'un coup palette/bandeau/erreurs ; `serieCanvas(i)` + migration des 6 fichiers chart + `styles` des 98 indicateurs ; `shouldFormatBigNumber` sur OI/macro ; promotion `formatFunding`/`formatUsdSigne`/`Fraicheur` ; `MenuDeroulant` en tokens + token `--warn` ; en-tête LIQ ; mnémonique FUND ; aide « ? » dérivée du registre ; sémantique workspaces tranchée ; palette : séparation symbole/commande + toast-undo ; AZERTY (`e.code`) ; toggleWindow restaure ; taskbar wrap. **Et les garde-fous qui empêchent la 3ᵉ dérive** : test anti-hex dans `chart/`, test mnémoniques uniques, test aide=registre, lint anti-`/NN` sur tokens (ou support alpha complet).
2. **Lot B — Lecture interprétée** : XSTAT, zones on-chain (H17), funding APR+percentile (H18), chapeau BRIEF+ (H16), REGIME (H19), baseline LIQ, extrêmes screener, hiérarchie VOL/FUNDX/STBL (depeg visible).
3. **Lot C — Features différenciantes** : CVDX, DELTAMAP, JRNL-CHART, FOCUS, WS-KEYS, SNAP (les S), puis PULSE et TIMELINE si appétit (M).

Chaque lot = spec → plan → implémentation → `pnpm -r test` + typecheck + build + contrôle visuel multi-thèmes, comme d'habitude.
