# PACTE V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire une application web locale complète qui rapproche contrats et transactions, détecte cinq situations explicables, puis prépare et suit une réclamation validée par l’utilisateur.

**Architecture:** Une nouvelle app Vite/React isolée dans `apps/pacte`. Le domaine TypeScript pur contient modèle, importeurs, analyse et génération de courrier ; React ne fait qu’orchestrer ces fonctions. Un état versionné est persisté dans `localStorage`, avec jeu de démonstration, sauvegarde et restauration.

**Tech Stack:** TypeScript 5.6 strict, React 18, Vite 5, Vitest 2, CSS natif ; aucune dépendance runtime nouvelle.

## Global Constraints

- Interface et documentation en français.
- L’application fonctionne sans serveur, compte, secret ni appel réseau.
- Aucune donnée n’est envoyée hors du navigateur.
- Les fichiers bruts ne sont pas persistés ; uniquement les faits confirmés et un extrait utile.
- Les alertes sont déterministes, explicables et toujours présentées comme à confirmer.
- Aucun conseil juridique personnalisé et aucun envoi automatique.
- Montants internes : débit positif, remboursement/crédit négatif.
- Dates internes : ISO `YYYY-MM-DD` ; rendu utilisateur en `fr-CH`.
- Aucune dépendance ajoutée au monorepo ; réutiliser les versions déjà verrouillées.
- Chaque tâche conserve `pnpm --filter @pacte/web typecheck` et les tests ciblés au vert.

- [ ] **Step 4: Implémenter les cinq règles isolées**

Chaque règle retourne `Anomaly[]`; `analyseState` les concatène, retire les

manquant récupère le montant attendu.

- [ ] **Step 5: Implémenter le score**

et 5 points par contrat actif sans prochaine échéance, puis borner entre 0 et
100. Le score est une mesure de complétude du contrôle, jamais une note
juridique.

une échéance proche. Les transactions couvrent chaque règle sans produire de
doublon involontaire.
